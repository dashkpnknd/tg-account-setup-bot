# TG Account Setup Bot

Кнопочный Telegram-бот для оформления принадлежащих вам Premium-аккаунтов по одному профилю и каналу-источнику.

## Что делает

- добавляет аккаунт через QR-вход;
- копирует имя, описание и фото профиля-источника, предварительно очищая emoji-status и эмодзи в имени;
- автоматически подбирает связанные username для профиля и нового канала;
- создаёт канал, копирует его название, описание, фото и посты;
- делает канал персональным каналом профиля, если функция доступна в текущей версии Telegram; нужный emoji-status владелец выставляет вручную после оформления;
- выдерживает случайную паузу от 3:00 до 6:59 между изменениями профиля и канала;
- запускает **полное** копирование историй: закреплённые и текущие истории источника отправляются по порядку с интервалом 60 минут;
- назначает неиспользованную почту из загруженной базы;
- после присланного вами кода меняет пароль 2FA и привязывает почту;
- отправляет итоговую карточку в личный чат и в канал «Telegram доступ».

## Запуск на сервере

```bash
cd /root/github-sync/tg-account-setup-bot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
nano .env
.venv/bin/python bot.py
```

В `.env` нужны `API_ID` и `API_HASH` приложения Telegram, а также `BOT_TOKEN`. База, сессии и `.env` исключены из Git.

По умолчанию `ACCOUNT_ACTION_PAUSE_MIN_MINUTES=3`, `ACCOUNT_ACTION_PAUSE_MAX_MINUTES=6` и `STORY_INTERVAL_MINUTES=60`. Эти значения можно изменить в `.env`. Привязка почты отключена по умолчанию; для возврата этапа задайте `ENABLE_EMAIL_BINDING=1`.

Для закрытия доступа задайте `ADMIN_IDS` как список числовых Telegram ID через запятую. Если он пустой, владелец первого `/start` становится администратором — это удобно только для первого запуска нового приватного бота.

## Первый сценарий в боте

1. В «Источник и настройки» указать профиль-источник, канал-источник, основу username, канал «Telegram доступ» и новый пароль.
2. В «Загрузить почты» прислать текстовый файл в виде `email:пароль`.
3. В «Добавить аккаунт по QR» отсканировать QR уже купленным Premium-аккаунтом.
4. Открыть аккаунт в «Оформить аккаунт» и нажать «Запустить оформление».
5. Когда бот пришлёт назначенную почту, войти в неё и прислать код боту. Бот завершит смену пароля и привязку почты.

Не добавляйте `.env`, SQLite-базу или сессии в Git. После запуска замените токен, который был отправлен в чат, в @BotFather.
